Une fiche par nombre publié : ce qu'il mesure, sur quel champ, avec quelles sources et quels seuils, et ce qu'il ne dit pas. Les seuils affichés ici sont vérifiés par des tests automatiques contre ceux qu'utilisent réellement les calculs.

Règles communes

  • Un taux calculé sur un groupe (bacheliers d'une doublette, candidats d'un profil) décrit ce qui s'est passé pour ce groupe ; ce n'est jamais une probabilité individuelle.
  • Les cases masquées par le secret statistique ne sont jamais remplacées par zéro.
  • Les calculs faits dans le navigateur sont testés pour donner exactement les mêmes nombres que les scripts d'analyse.
  • Une conclusion corrigée après vérification est consignée dans le journal des corrections du code source.
